# Campus Hub

Мобильное приложение для студентов на Expo и React Native с собственным сервером на Node.js и SQLite.

Разделы: библиотека, транспорт Алматы (Almaty Bus), столовая, общежитие со стиркой, студенты, подписка, справочная информация и панель администратора. Интерфейс на русском и казахском, есть английский.

## Запуск

Нужен Node.js 24 или новее: сервер использует встроенный модуль `node:sqlite`.

```bash
npm install
```

```bash
npm run server
```

Во втором окне терминала:

```bash
npx expo start
```

Затем откройте проект в Expo Go. Телефон и компьютер должны быть в одной сети Wi-Fi: приложение само находит сервер на том же компьютере (порт 3000). Если брандмауэр спросит про доступ для Node.js, разрешите доступ в частной сети.

База данных создаётся при первом запуске в `server/data/campus.db`. Демо-пользователей в ней нет.

## Первый администратор

Зарегистрируйтесь в приложении, затем выполните команду со своим email:

```bash
node server/index.js --make-admin ваш@email.com
```

Перезапустите приложение: в профиле появится кнопка «Админ-панель». Права проверяет сервер, поэтому обычный пользователь получит отказ, даже если обратится к API напрямую.

Администратор управляет книгами, меню и ценами, страницами «Информации», общежитиями, машинами и справочником факультетов и специальностей. Ещё он меняет статусы заказов и заявок, видит брони и может вручную выдать подписку.

## Настройки

| Где | Переменная | Назначение |
| --- | --- | --- |
| Сервер | `PORT` | Порт, по умолчанию 3000 |
| Сервер | `DB_PATH` | Путь к файлу базы данных |
| Сервер | `ADMIN_EMAIL` | Этот email получит роль администратора при регистрации |
| Сервер | `BUS_POSITIONS_URL` | Источник координат автобусов: JSON-массив `{routeNumber, lat, lon}` |
| Сервер | `SEED_DEMO_DORM` | `0` — не создавать демо-общежитие |
| Приложение | `EXPO_PUBLIC_API_URL` | Адрес сервера, обязателен для сборки в магазин |

Примеры: `server/.env.example` и `.env.example`. Секреты в код приложения записывать нельзя.

## Сборка для Android и iOS

Сборка выполняется в Expo Application Services, нужен бесплатный аккаунт Expo. Для iOS нужен платный аккаунт Apple Developer.

```bash
npx eas-cli build --platform android --profile preview
```

```bash
npx eas-cli build --platform ios
```

Перед сборкой нужно:

1. Разместить сервер на хостинге с https и указать адрес в `EXPO_PUBLIC_API_URL`.
2. Задать идентификаторы приложения: `android.package` и `ios.bundleIdentifier` в `app.json`.
3. Для карты на Android получить ключ Google Maps и добавить его в настройки плагина `react-native-maps`. В Expo Go ключ не нужен.

## Откуда данные

- **Маршруты автобусов:** OpenStreetMap (лицензия ODbL), обновление: `npm run data:bus`. Полнота зависит от OpenStreetMap: у части маршрутов нет остановок или линия прерывается.
- **Книги:** Open Library, обновление: `npm run data:books`. Каждая книга проверена по ISBN или поиску по названию и автору.
- **Обложки:** Google Books и Open Library, хранятся в `server/data/covers`, обновление: `npm run data:covers`.
- **Фото блюд:** Wikimedia Commons, авторы и лицензии в `assets/images/CREDITS.md`.
- **Меню, цены и тарифы:** примеры, администратор заменяет их настоящими.
- **Университет, факультеты, контакты:** заполняет администратор, выдуманных сведений нет.

## Что не подключено

- **Оплата.** Платёжной системы нет: сервер отвечает отказом, деньги не списываются. Подписку может выдать администратор.
- **Автобусы в реальном времени.** Без `BUS_POSITIONS_URL` на карте только маршруты и остановки.
- **Письма и SMS.** Код восстановления пароля выводится в консоль сервера.
- **Расписание, Planonus ALT, журнал, тренировки, читальный зал.** Это примерные данные с пометкой на экране, они не связаны с системами университета.
- **Абонемент.** Заявка оформляется в приложении, оплата проходит на месте, включает абонемент администратор.

## Безопасность

- Пароли хранятся только как хеш scrypt с солью.
- Токены сессий хранятся на сервере как SHA-256, на телефоне — в защищённом хранилище (`expo-secure-store`). В веб-версии такого хранилища нет, поэтому она подходит только для просмотра.
- Цены заказов, лимиты тарифов, конфликты броней и роль администратора проверяет сервер.
- Попытки входа и запросы кода восстановления ограничены: не больше 10 за 15 минут.
